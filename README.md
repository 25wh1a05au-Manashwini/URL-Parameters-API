# URL Parameters & Product Lookup API

## Description
A simple REST API developed using Node.js and Express.js.

## API Route
GET /api/shop/:category/:id

## Example URL
http://localhost:3000/api/shop/electronics/101

## Output
{
  "category": "electronics",
  "id": "101"
}

## How to Run
1. Install Node.js.
2. Run npm install.
3. Run node app.js.
4. Open the example URL in your browser.
5.The API displays the category and product ID in JSON format
